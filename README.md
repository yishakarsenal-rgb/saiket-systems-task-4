Interactive HTML Forms & Validation — Saiket Systems Task 4

A modern, responsive, pitch-black contact form web page built using **HTML5** and **CSS3**. Developed as part of the **Saiket Systems** Web Development Internship to demonstrate complete form structure, control elements, and native client-side validation.

Features

-Complete Form Controls:Integrates text inputs, email inputs, custom dropdown select menus (`<select>`), radio button groups, multi-select checkboxes, textareas, and submit action buttons.
-Native HTML5 Validation:Built-in constraint validation (`required`, email patterns) ensuring required fields are populated prior to submission.
-Responsive Layout:Styled using CSS Flexbox and Grid to scale seamlessly across mobile devices, tablets, and desktop displays.
-Semantic HTML Architecture:Built following web accessibility guidelines with explicit label pairings (`for=""` / `id=""`) and proper ARIA tags.

Tech Stack

-HTML5:Form semantics, native validation constraints, and input types
-CSS3:Custom properties (variables), Flexbox, CSS Grid, custom controls styling, and responsive media queries
